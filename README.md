# Analiza sprzedaży sklepu 📊

Mały projekt analityczny: dane sprzedażowe sklepu internetowego, zapytania SQL i skrypt w Pythonie, który robi wykres.

## Struktura
- `dane/` – dane sprzedażowe (CSV)
- `sql/` – zapytania SQL
- `python/` – skrypty do analizy i wykresów

Projekt demo od [Ninja Data](https://ninjadata.pl).

## Raporty
1. Przychód miesięcznie – `sql/sprzedaz_miesiecznie.sql`
2. Top 3 produkty – `sql/top_produkty.sql`
3. Wykres przychodu – `python/wykres.py`
